# Diseño del cliente REST

Usar la vista del servidor como fuente de mano, solicitud, marcador y resultado. Mantener presencia y actualizar la presentación durante la selección y la pausa. Conservar el ID y los datos de una elección con respuesta incierta para consultar su recibo antes de reenviar. Distinguir errores de entrada, conflicto de estado y fallos de comunicación según el contrato.
